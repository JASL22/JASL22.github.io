# Portafolio de Jhonn Saeteros

Este proyecto reúne tres propuestas de portafolio personal creadas con ayuda de herramientas de inteligencia artificial. La página principal, `index.html`, presenta el proyecto y permite abrir cada propuesta para explorar sus diferentes diseños y formas de navegación.

## Objetivo del proyecto

El objetivo es experimentar con ChatGPT, Claude y DeepSeek como herramientas de apoyo para crear distintas versiones de un mismo portafolio. La comparación permite observar cómo pueden variar el diseño visual, la organización y presentación del contenido, la estructura de las páginas, los elementos interactivos y la experiencia de navegación.

El proyecto también sirve para explorar y reflexionar sobre los diez principios de usabilidad de Jakob Nielsen:

1. **Visibilidad del estado del sistema:** comunicar al usuario qué está ocurriendo.
2. **Correspondencia con el mundo real:** usar lenguaje y conceptos familiares.
3. **Control y libertad del usuario:** facilitar la navegación y la salida de una acción.
4. **Consistencia y estándares:** mantener patrones conocidos y coherentes.
5. **Prevención de errores:** diseñar para evitar problemas antes de que ocurran.
6. **Reconocimiento antes que recuerdo:** mantener visibles las opciones y acciones.
7. **Flexibilidad y eficiencia de uso:** permitir interacciones cómodas para distintos usuarios.
8. **Diseño estético y minimalista:** priorizar el contenido relevante.
9. **Reconocer, diagnosticar y corregir errores:** ofrecer mensajes claros y útiles.
10. **Ayuda y documentación:** facilitar orientación cuando sea necesaria.

Las propuestas son diferentes aproximaciones para observar estos principios en una interfaz; el propósito es compararlas y evaluar sus decisiones de diseño y usabilidad.

## Estructura del proyecto

```text
.
├── index.html                  # Página principal y punto de entrada
├── Portafolio Chatgpt.html     # Propuesta desarrollada con ayuda de ChatGPT
├── Portafolio Claude.html      # Propuesta desarrollada con ayuda de Claude
├── Porfafolio Deepseek.html    # Propuesta desarrollada con ayuda de DeepSeek
└── README.md                   # Descripción y documentación del proyecto
```

> El archivo de DeepSeek conserva el nombre `Porfafolio Deepseek.html` para que coincida con el enlace existente en la página principal.

## Tecnologías utilizadas

- **HTML5** para la estructura y el contenido de las páginas.
- **CSS3** para los diseños, colores, animaciones y adaptación a distintos tamaños de pantalla.
- **JavaScript** para las interacciones de las propuestas y funciones como el cambio entre modo claro y oscuro en la página principal.
- **Google Fonts** para las tipografías externas utilizadas en las propuestas de ChatGPT y Claude.

El sitio no requiere un framework ni un proceso de compilación.

## Herramientas de inteligencia artificial

- **ChatGPT:** apoyo en la generación y exploración de una propuesta de portafolio.
- **Claude:** apoyo en la creación de una segunda propuesta con decisiones visuales y de navegación propias.
- **DeepSeek:** apoyo en la elaboración de una tercera alternativa.

Las herramientas se utilizaron como apoyo para experimentar con diferentes maneras de presentar la misma información. El resultado permite comparar sus propuestas y analizar cómo se relacionan con los principios de usabilidad de Nielsen.

## Cómo visualizar el proyecto

1. Descarga o clona el repositorio.
2. Abre `index.html` en un navegador web.
3. Selecciona una de las tres propuestas para visitar su página.
4. Usa el botón **Atrás** del navegador para volver al inicio y explorar otra versión.
